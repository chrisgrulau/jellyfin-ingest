    Quarantine

    Clutter from filed releases, and releases quarantined from review, kept by date until the retention period ends.

    Watch folders

    Each release is filed by type into the watch folder's destination for that kind: shows into a Shows library, films into a Movies library, or both into a Mixed Movies and Shows library. A watch folder can have one destination per kind, so a mixed library must be its only destination. Media with no destination of its kind is left for review. To split films between two Movies libraries, use a watch folder for each.

    Settings

    Leave empty to use a hidden .ingest-quarantine folder inside each watch folder (same disk, so moves are instant). It must not be, contain or sit inside a library folder; only the dated folders Ingest creates there are ever deleted.
    A release is processed once no file in it has been added, resized or written for this long. Download clients must not write straight into a watch folder: use their "incomplete" or temporary folder outside it (or an in-progress suffix such as .part or .!qb) and let them move finished downloads in. A download that stalls for longer than this can otherwise look finished.
    Only the film or show folders that were filed into are refreshed, so new items appear within a minute or so without scanning whole libraries.

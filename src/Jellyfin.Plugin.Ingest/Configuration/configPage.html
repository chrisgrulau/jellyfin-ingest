      Settings

      Watch folders

      A new watch folder starts in dry run: Ingest records what it would do (see Recent activity) and moves nothing until you untick it for that folder. Releases are filed by kind: shows into a Shows library, films into a Movies library, or both into a Mixed Movies and Shows library (which must then be the folder's only destination). Media with no destination of its kind waits for review. To split films between two Movies libraries, use a watch folder for each.

      Processing
      A release is processed once no file in it has been added, resized or written for this long. Download clients must not write straight into a watch folder: use their "incomplete" or temporary folder outside it (or an in-progress suffix such as .part or .!qb) and let them move finished downloads in. A download that stalls for longer than this can otherwise look finished.
      Only the film or show folders that were filed into are refreshed, so new items appear within a minute or so without scanning whole libraries.

      Quarantine
      Leave empty to use a hidden .ingest-quarantine folder inside each watch folder (same disk, so moves are instant). It must not be, contain or sit inside a library folder; only the dated folders Ingest creates there are ever deleted.

      AI help
      Only when the Shoal AI plugin is installed and allows Ingest (its settings page, where its spending limits also apply). When two or more candidates are too close to call, it picks one of them, using only the file name and the candidates' titles and years. When a file names its episode by title only (a special, say) and no title matches clearly, it picks one of that season's episodes from their titles and short synopses. Anything else waits for review as before. Each settled match is marked 🤖 in Recent activity, with the reason in its details.
      When an episode's name doesn't say which episode it is, the Shoal Subtitles plugin transcribes two minutes of it and the AI plugin compares that with the episode synopses. Needs both plugins, with Let Ingest ask for short transcripts on in the Subtitles plugin (built-in speech-to-text is free and stays on this server). The AI must pick one of the show's listed episodes; anything else waits for review.

      Notifications
      Releases waiting for your decision, failures, filings and quarantines also appear under Dashboard → Activity (at most once a day for the same release and outcome), so they're seen without opening this page.

Ingest

New media dropped into a watch folder is identified, renamed to Jellyfin's naming standard and moved into the chosen library with its subtitles. Anything else in the release is quarantined and deleted after the retention period. Releases that can't be identified confidently are left where they are; see the Jellyfin log.

Dry run is on. Ingest logs what it would do and moves nothing. Check the log, then turn dry run off.
